# BACKLOG OFICIAL DO MIKAON

> Documento oficial do backlog do MikaON.
>
> Este documento centraliza todas as melhorias, ideias e funcionalidades aprovadas para desenvolvimento futuro.
>
> Nenhuma ideia importante deverá permanecer apenas em conversas.

---

# Objetivo

Centralizar todas as funcionalidades futuras do MikaON.

O backlog representa tudo aquilo que já foi aprovado conceitualmente, mas ainda não foi implementado.

---

# Como utilizar

Cada item deverá possuir:

- ID
- Módulo
- Prioridade
- Status
- Descrição
- Impacto
- Dependências

# Ideias Permanentes

Além das funcionalidades acima, permanecem aprovadas como diretrizes do projeto:

- reduzir continuamente a quantidade de cliques;
- aumentar a produtividade dos operadores;
- reutilizar componentes sempre que possível;
- documentar toda decisão importante;
- manter alta densidade de informação sem comprometer a legibilidade;
- evoluir o sistema com base na operação real da MiKATECH.

---

# Inclusão de Novas Ideias

Sempre que surgir uma nova ideia aprovada durante uma conversa, ela deverá ser registrada neste documento antes de virar Sprint.

---

# Objetivo Final

Garantir que nenhuma funcionalidade importante do MikaON seja esquecida, permitindo que o roadmap evolua de forma organizada e priorizada.
