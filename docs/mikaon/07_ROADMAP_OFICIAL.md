# ROADMAP OFICIAL DO MIKAON

> Documento oficial de evolução do projeto.
>
> Este roadmap define a visão de longo prazo do MikaON.
> Toda nova funcionalidade deverá ser planejada considerando este documento.

---

# Objetivo

Transformar o MikaON em uma plataforma SaaS completa de gestão empresarial, preparada para milhares de empresas e diferentes segmentos de mercado.

O crescimento do sistema será contínuo, organizado e baseado em arquitetura modular.

---

# Visão Final

O MikaON será composto pelos seguintes grandes módulos:

- ERP
- CRM
- PDV
- Financeiro
- Compras
- Estoque
- Ordem de Serviço
- Produção
- Fiscal
- BI
- Agenda
- Portal do Cliente
- Portal do Vendedor
- Aplicativo Mobile
- API Pública
- Marketplace de Integrações
- Inteligência Artificial

Todos compartilharão uma única base de dados.

# Filosofia de Desenvolvimento

Toda nova funcionalidade deverá responder positivamente às seguintes perguntas:

- melhora a produtividade?
- melhora a experiência do usuário?
- reutiliza componentes existentes?
- mantém a arquitetura?
- mantém compatibilidade?
- está documentada?

Caso alguma resposta seja negativa, a implementação deverá ser reavaliada.

---

# Prioridade Permanente

A ordem oficial de prioridades do MikaON será sempre:

1. Estabilidade
2. Arquitetura
3. Performance
4. Segurança
5. Experiência do Usuário
6. Novas Funcionalidades

Essa ordem nunca deverá ser invertida.
